# মেস ম্যানেজার (Mess Manager)

একটি আধুনিক এবং সহজ মেস ম্যানেজমেন্ট ওয়েব অ্যাপ্লিকেশন, যা দিয়ে মেসের মিল, খরচ, জমা এবং সদস্যদের হিসাব স্বয়ংক্রিয়ভাবে পরিচালনা করা যায়।

## 🚀 ফিচারসমূহ (Features)

- **সদস্য এবং অ্যাডমিন অথেনটিকেশন:**
  - মেম্বাররা নিজেদের নাম, মোবাইল নম্বর এবং পিন দিয়ে রেজিস্ট্রেশন ও লগইন করতে পারে।
  - অ্যাডমিন আলাদা পিন দিয়ে লগইন করে সম্পূর্ণ মেস পরিচালনা করতে পারে।
- **দৈনিক মিল ট্র্যাকিং:**
  - সকাল এবং রাতের মিল আলাদাভাবে হিসাব করার সুবিধা।
  - সদস্যরা নিজেরাই প্রতিদিনের মিল এন্ট্রি/আপডেট করতে পারে।
- **জমা ও খরচের হিসাব:**
  - সদস্যদের জমা টাকা সংরক্ষণ ও দেখা।
  - মেসের দৈনিক বাজার ও অন্যান্য খরচের হিসাব রাখা।
- **স্বয়ংক্রিয় ক্যালকুলেশন:**
  - মিল রেট, মোট মিল, মোট খরচ এবং ব্যালেন্স স্বয়ংক্রিয়ভাবে হিসাব হয়।
- **ডাটাবেজ ইন্টিগ্রেশন:**
  - MongoDB Atlas ক্লাউড ডাটাবেজ সাপোর্ট।

## 🛠️ টেকনোলজি (Tech Stack)

- **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla ES6)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose ODM)

## 📦 যেভাবে চালাবেন (Setup Instructions)

১. রিপোজিটরিটি ক্লোন করুন:
```bash
git clone <your-repository-url>
cd WE_R_5
```

২. প্যাকেজসমূহ ইনস্টল করুন:
```bash
npm install
```

৩. পরিবেশ ভেরিয়েবল কনফিগার করুন:
প্রজেক্টের রুট ডিরেক্টরিতে একটি `.env` ফাইল তৈরি করুন এবং নিচের মানগুলো বসান:
```env
PORT=3000
MONGO_URI=your_mongodb_connection_string
```

৪. সার্ভার চালু করুন:
```bash
node server.js
```

৫. ব্রাউজারে প্রবেশ করুন:
[http://localhost:3000](http://localhost:3000)
