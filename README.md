## 📖 প্রজেক্ট পরিচিতি (Project Overview)

**মেস ম্যানেজার (Mess Manager)** হলো একটি সম্পূর্ণ আধুনিক, দ্রুত এবং নির্ভরযোগ্য ফুল-স্ট্যাক মেস ও হোস্টেল অ্যাকাউন্টিং সিস্টেম। এটি প্রচলিত খাতার জটিল হিসাব-নিকাশের আধুনিক ডিজিটাল সমাধান। মেম্বারদের দৈনিক মিল ট্র্যাকিং, বাজার খরচের হিসাব, জমা টাকার হিসাব, মিল রেট নির্ধারণ, ৩ মাসের স্বয়ংক্রিয় ব্যাকআপ এবং ঐতিহ্যবাহী খাতার ফরম্যাটে **দ্বিভাষিক PDF স্টেটমেন্ট** জেনারেট করার যাবতীয় সুবিধা এতে রয়েছে।

## ✨ প্রধান ফিচারসমূহ (Key Features)

### 📊 ১. লাইভ ড্যাশবোর্ড (Live Calculation Dashboard)
- **স্বয়ংক্রিয় মিল রেট ইঞ্জিন:** মোট বাজার খরচকে মোট মিল দিয়ে ভাগ করে তাৎক্ষণিক লাইভ মিল রেট হিসাব।
- **মেসের মূল মেট্রিক্স:** মোট জমা (Total Deposit), মোট বাজার খরচ (Total Bazar Cost), মোট মিল (Total Meals) এবং বর্তমান মিল রেট (Meal Rate)।
- **সদস্যদের হিসাব বিবরণী:** প্রতিটি সদস্যের মোট জমা, মোট মিল, মিল খরচ এবং বর্তমান অবস্থা (পাওনা / বাকি) স্পষ্ট কালার কোডিং সহ প্রদর্শন।

### 📄 ২. দ্বিভাষিক প্রিন্ট ও ডাউনলোডযোগ্য PDF স্টেটমেন্ট (A4 Mess Statement Sheet)
- **খাতার আদলে ফরম্যাট:** বাংলাদেশি মেস পরিচালনার ঐতিহ্যবাহী খাতার ছকের সাথে ১০০% সামঞ্জস্যপূর্ণ।
- **Bilingual Columns:** বাংলা ও ইংরেজি উভয় ভাষায় স্পষ্ট লেবেল (`NAME`, `TOTAL MEALS`, `TOTAL DEPOSIT`, `ADDITIONAL`, `TOTAL COST`, `MEAL GET`, `MEAL SEND`)।
- **অতিরিক্ত খরচের সমন্বয় (Additional Cost):** ওয়াইফাই, গ্যাস, খালা বিল ইত্যাদি এককালীন অতিরিক্ত খরচ দিলে তা সদস্যদের মাঝে মাথাপিছু সমানভাবে ভাগ করে মোট খরচে সমন্বয়ের সুযোগ।
- **প্রিন্ট ও PDF এক্সপোর্ট:** উচ্চ রেজোলিউশনের A4 সাইজ পোরট্রেট মোডে ডাউনলোডযোগ্য (`html2pdf.js`) ও ম্যানেজার/মেম্বার স্বাক্ষরের নির্ধারিত স্থান।

### 🗄️ ৩. বিগত ১২ মাসের স্বয়ংক্রিয় ব্যাকআপ (12-Month Rolling Archive)
- **অটো-রোলিং ব্যাকআপ:** প্রতি মাসের শেষে এবং সার্ভার চালুর সাথে সাথে স্বয়ংক্রিয়ভাবে বিগত ১২ মাসের পূর্ণাঙ্গ ব্যাকআপ তৈরি হয়।
- **অটো-ক্লিনআপ:** ১২ মাসের পুরনো ব্যাকআপ ফাইল স্বয়ংক্রিয়ভাবে ডিলিট হয়ে সার্ভারের স্টোরেজ অপ্টিমাইজড থাকে।
- **JSON ও PDF এক্সপোর্ট:** সংরক্ষিত যেকোনো মাসের পূর্ণাঙ্গ ব্যাকআপ ফাইল (JSON) ডাউনলোড করা এবং পেছনের মাসের স্টেটমেন্ট শিট দেখার সুবিধা।

### 👥 ৪. সদস্য ডসিয়ার ও প্রোফাইল ছবি (Member Dossier & Photo Upload)
- **অ্যাডমিন ডসিয়ার ভিউ:** মেম্বারদের নাম, ফোন নম্বর, রুম নম্বর ছাড়াও প্রয়োজনীয় ডকুমেন্টস ও জাতীয় পরিচয়পত্র/ছবি সুরক্ষিতভাবে আপলোড ও সংরক্ষণের সুবিধা।
- **মেম্বার সেলফ-সার্ভিস:** মেম্বাররা তাদের নিজস্ব প্রোফাইলে লগইন করে নিজেদের পছন্দমতো প্রোফাইল ছবি সেট বা পরিবর্তন করতে পারেন।
- **গোপনীয়তা ও নিরাপত্তা:** মেম্বারদের আপলোডকৃত সংবেদনশীল ডকুমেন্টস শুধুমাত্র অ্যাডমিন দেখতে পারেন।

### 🍽️ ৫. দৈনিক মিল ট্র্যাকিং ও অ্যাডমিন কন্ট্রোল (Daily Meal Management)
- **সকাল ও রাতের মিল বিভাজন:** প্রতিটি দিনের জন্য সকাল (Lunch/Morning) এবং রাতের (Dinner/Night) মিল আলাদাভাবে হাফ (০.৫) বা ফুল (১, ২, ৩...) আকারে এন্ট্রি।
- **অটো-সিঙ্ক:** মেম্বাররা নিজেদের আইডি দিয়ে লগইন করে মিল সাবমিট করলে তা ডাটাবেজে তাৎক্ষণিক রিয়েল-টাইমে যুক্ত হয়ে যায়।
- **অ্যাডমিন সরাসরি এডিট ও ডিলিট:** অ্যাডমিন চাইলে সরাসরি Member Details প্যানেল থেকে যেকোনো সদস্যের পূর্বের মিল পরিবর্তন, নতুন মিল যোগ বা ডিলিট করতে পারেন।

### 💰 ৬. জমা ও বাজার খরচের হিসাব (Deposit & Expense Management)
- সদস্যভিত্তিক টাকা জমার তারিখ ও রসিদ সংরক্ষণ।
- বাজার খরচের পরিমাণ, তারিখ এবং বাজারের বিবরণী (Note) সহ তালিকা।
- ভুল এন্ট্রি মুছে ফেলার তাৎক্ষণিক ডিলিট ব্যবস্থা।

### 🔐 ৭. রোল-বেসড অথেনটিকেশন (Role-Based Access Control)
- **মেম্বার লগইন:** মোবাইল নম্বর ও পাসওয়ার্ড/পিন দিয়ে নিরাপদ লগইন ও স্বয়ংক্রিয় সেশন হ্যান্ডলিং।
- **অ্যাডমিন সুরক্ষা:** অ্যাডমিন বিশেষ পিন কোডের মাধ্যমে সুরক্ষিত অ্যাডমিন ড্যাশবোর্ড নিয়ন্ত্রণ করতে পারেন।

## ⚙️ লোকাল সেটআপ নির্দেশিকা (Installation & Setup)

### ১. রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/Tadbir20/WE_R_5.git
cd WE_R_5
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ৩. পরিবেশ ভেরিয়েবল সেটআপ করুন:
প্রজেক্টের রুট ডিরেক্টরিতে একটি `.env` ফাইল তৈরি করুন এবং আপনার MongoDB কানেকশন স্ট্রিং দিন:
```env
PORT=3000
MONGO_URI=mongodb+srv://<username>:<password>@cluster0.mongodb.net/mess_manager?retryWrites=true&w=majority
```

### ৪. সার্ভার চালু করুন:
```bash
# প্রোডাকশন স্টার্ট
npm start

# অথবা ডেভেলপমেন্ট মোড
node server.js
```

### ৫. ব্রাউজারে অ্যাপ ওপেন করুন:
ব্রাউজারে গিয়ে প্রবেশ করুন:
```
http://localhost:3000
```

## 🔌 প্রধান API এন্ডপয়েন্টসমূহ (API Endpoints)

| Method | Endpoint | কাজ (Description) |
| :--- | :--- | :--- |
| `GET` | `/api/members` | সকল সদস্যের তালিকা প্রদর্শন |
| `POST` | `/api/members/register` | নতুন সদস্য রেজিস্ট্রেশন |
| `POST` | `/api/members/login` | সদস্য লগইন |
| `POST` | `/api/members/upload-doc` | মেম্বার ছবি/ডকুমেন্ট আপলোড (Multer) |
| `GET` | `/api/deposits` | সকল জমার রেকর্ড সংগ্রহ |
| `POST` | `/api/deposits` | নতুন টাকা জমা এন্ট্রি |
| `GET` | `/api/expenses` | বাজার খরচের বিবরণী সংগ্রহ |
| `POST` | `/api/expenses` | নতুন বাজার খরচ এন্ট্রি |
| `GET` | `/api/meals` | দৈনিক মিল তালিকা সংগ্রহ |
| `POST` | `/api/meals` | দৈনিক মিল সংরক্ষণ / আপডেট |
| `GET` | `/api/backups` | বিগত ১২ মাসের ব্যাকআপের তালিকা |
| `GET` | `/api/backups/data/:month` | নির্দিষ্ট মাসের ফ্রেশ ব্যাকআপ ডাটা সংগ্রহ |
| `POST` | `/api/backups/create` | তাৎক্ষণিক নতুন ব্যাকআপ তৈরি |
